# Plan Versions

This folder holds executable planning packages for large Qentrah changes.

## Active plan

- [Work OS Hard Reset V1](./work-os-hard-reset-v1/README.md)

## Rules

- Start from the active plan version before editing runtime code.
- Use the plan task ids in notes, commits, and verification summaries.
- Do not mark a task complete until its task file acceptance gate is satisfied.
- Create a new version folder for a materially different strategy.
- Task files may use task-id prefixes because this folder is an execution
  workflow, not stable topical documentation.

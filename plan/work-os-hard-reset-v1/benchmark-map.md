# Benchmark Map

Use the competitor study as a roadmap input and acceptance checklist. Do not
ship it as a user-facing feature in V1.

## V1 baseline capabilities

- Flexible records with custom fields.
- Table, board, calendar, and detail views where they fit the record.
- Task and project management with ownership, status, priority, dates, and links.
- Opportunity pipeline with stages, value, client, next step, and owner.
- Record links across clients, opportunities, projects, tasks, events, and assets.
- Automations for common deterministic record actions.
- AI assistant that summarizes, plans, drafts, and proposes confirmed actions.
- MCP tools for generic Work OS records.
- Connector authorization, sync contracts, and action audit.

## V2 candidates

- Docs and knowledge base.
- Workload and resource planning.
- Advanced dashboards and analytics.
- Request forms and external intake.
- Time tracking.
- Whiteboards or collaborative canvases.
- Advanced AI evals and multi-step agent workflows.

## Benchmark interpretation

- ClickUp and monday.com set the high bar for breadth, custom fields, views,
  automations, dashboards, and flexible workspaces.
- Asana sets a strong baseline for projects, goals, forms, dependencies, and
  collaboration clarity.
- Jira sets the bar for structured work tracking, permissions, boards, and
  technical workflow depth.
- Notion sets the bar for flexible databases, docs, and lightweight workspace
  composition.
- Trello sets the baseline for simple board-first task workflows and automation.
- Wrike sets the baseline for operational project management, reporting, and
  resource coordination.

## Rule

If a benchmark capability is not in V1, keep it out of implementation tasks and
record it as V2. Do not silently expand a V1 task into broad competitor parity.

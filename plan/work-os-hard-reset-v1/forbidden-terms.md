# Forbidden Terms

These terms must not remain as first-class product concepts in active Work OS
code, APIs, prompts, schemas, UI, or docs.

## Forbidden as core language

- property
- properties
- unit
- units
- broker
- brokerage
- developer
- REGA
- listing
- listings
- viewing
- site viewing
- bedroom
- bedrooms
- bathroom
- bathrooms
- inventory
- title deed

## Allowed exceptions

- Historical docs that explicitly describe the old real-estate model.
- Decision logs that record past architecture.
- Benchmark notes that quote or explain external material.
- Future workspace template examples where real estate is clearly optional and
  not core infrastructure.

## Gate

The final task must run a forbidden-term search and classify every remaining
match as removed, renamed, or allowed exception.

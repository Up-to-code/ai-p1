# Work OS Hard Reset V1

## Purpose

Convert Qentrah from a real-estate workspace into an industry-agnostic Work OS.
The core product model is clients, opportunities, projects, tasks, calendar
events, assets, automations, custom fields, record links, workspace templates,
and AI agents.

## Strategy

- Hard reset real-estate concepts from the core product.
- Keep real estate only as a future workspace template.
- Make each implementation task atomic and independently verifiable.
- Use the competitor study as roadmap input, not as a user-facing app feature.

The conversion is complete when every task in [tasks.md](./tasks.md) is checked,
the final acceptance report is written, and the forbidden-term gate proves that
active product code no longer uses real-estate language as core infrastructure.

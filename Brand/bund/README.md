# Qentrah Brand Bundle

This folder contains the rounded iOS-style Qentrah icon and the machine-readable rules for using it in app UI.

## Files

- `qentrah-icon-ios-rounded.png`: 1024px square PNG with white background, centered dark mark, and iOS-style rounded corners.
- `qentrah-icon-ios-rounded.svg`: editable SVG source for the same icon.
- `design-rules.json`: reusable UI, spacing, color, and logo handling rules.
- `stats.json`: measured asset dimensions and positioning values.

## Usage Rules

- Keep the mark centered with generous white space.
- Use the dark mark on a white background for launch, auth, and brand-identification surfaces.
- Do not crop, stretch, recolor, rotate, texture, shadow, or add elements around the mark.
- Do not imply an OpenAI partnership or endorsement. The OpenAI brand page is used only as a reference for clear-space and mark-handling discipline.

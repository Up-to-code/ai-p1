# Rules

Purpose: Explains lifecycle and platform rules that hide or allow records.

## Scope

This folder owns small, focused documentation files for rules.

This folder does not own broad system-wide specification text. If content crosses domains, link to the owning domain.

## Files

| File | Purpose |
| --- | --- |
| [Sold Hidden](sold-hidden.md) | Sold properties are hidden from marketplace visibility. |
| [Off Market Hidden](off-market-hidden.md) | Off-market properties are hidden from marketplace visibility. |
| [Leased Hidden](leased-hidden.md) | Leased state can require marketplace withdrawal depending on property and lease policy. |
| [Withdrawn Expired Rejected](withdrawn-expired-rejected.md) | Withdrawn, expired, rejected, and suspended records are not marketplace visible. |
| [Manual Hide](manual-hide.md) | Manual hide requires permission and reason. |
| [Platform Allow Rules](platform-allow-rules.md) | Platforms receive only approved scopes and visibility types. |

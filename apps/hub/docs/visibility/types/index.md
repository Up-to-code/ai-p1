# Types

Purpose: Explains specific visibility types.

## Scope

This folder owns small, focused documentation files for types.

This folder does not own broad system-wide specification text. If content crosses domains, link to the owning domain.

## Files

| File | Purpose |
| --- | --- |
| [Marketplace](marketplace.md) | Marketplace visibility is public listing visibility. |
| [Crm](crm.md) | CRM visibility is internal for owning publisher or approved CRM. |
| [Workspace Tool](workspace-tool.md) | Workspace visibility supports internal operational tools. |
| [Legal Government](legal-government.md) | Legal/Government visibility is restricted. |
| [Partner](partner.md) | Partner visibility is scoped by partner platform, app scopes, approval, and consent. |
| [Analytics](analytics.md) | Analytics visibility uses aggregate or redacted data. |
| [Suppression](suppression.md) | Suppression visibility records why data must be hidden or withdrawn. |

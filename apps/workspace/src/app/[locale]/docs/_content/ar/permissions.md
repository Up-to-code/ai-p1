description: "فكر في الصلاحيات كمفاتيح تشغيل. إذا كان المفتاح مغلقاً، فلن يرى الوكيل ذلك الجزء من الشركة."
---

الصلاحيات هي مفاتيح بسيطة. المفتاح يسمح للوكيل أن يقرأ أو ينشئ أو يحدث أو يحذف نوعاً من المعلومات. إذا كان المفتاح مغلقاً فلن تظهر الأداة للوكيل.

## جدول الصلاحيات

| المورد | الاستخدام الأفضل | الإجراءات المتاحة |
| :--- | :--- | :--- |
| **المؤسسة** | تعريف الوكيل بالشركة التي يساعدها | `قراءة` |
| **العملاء** | البحث عن العملاء وتلخيص احتياجاتهم وتجهيز المتابعات | `قراءة`، `إنشاء`، `تحديث`، `حذف` |
| **الأصول** | البحث عن الأصول المتاحة وشرح الخيارات للعميل | `قراءة`، `إنشاء`، `تحديث`، `حذف` |
| **المشاريع** | الإجابة عن أسئلة المشاريع ومقارنة العمل المرتبط بها | `قراءة`، `إنشاء`، `تحديث`، `حذف` |
| **التقويم** | عرض الاجتماعات أو جدولة المواعيد | `قراءة`، `إنشاء`، `تحديث`، `حذف` |
| **المهام** | إنشاء مهام للفريق بعد المحادثة | `قراءة`، `إنشاء`، `تحديث`، `حذف` |
| **الوسائط** | قراءة الملفات المعتمدة أو إرفاق مستندات عبر روابط | `قراءة`، `إنشاء` |

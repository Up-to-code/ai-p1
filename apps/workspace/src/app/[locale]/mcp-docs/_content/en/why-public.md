---
title: "Share the guide, not the dashboard"
label: "Why public"
description: "Public docs let vendors, admins, and agent builders understand the setup before they touch private company data."
---

This guide lives outside the dashboard because setup often involves people who should read the instructions but should not manage live access: vendors, AI consultants, developers, and operations leads.

Public docs explain the process. Qentrah's signed-in OAuth consent and MCP settings screens remain the only places where users approve, review, or revoke live agent access.

قبل ربط الوكيل راجع هويته والمؤسسة والنطاق والصلاحيات ومدة التفويض.

## أفضل ممارسات الأمان

* **استخدم نطاقاً ضيقاً**: فضّل المساحات أو المشاريع المحددة على كامل المؤسسة.
* **امنح الإجراءات المطلوبة فقط**: لا تفعّل الكتابة أو الحذف إلا عند الحاجة.
* **اختر مدة قصيرة**: استخدم 7 أو 30 يوماً للوكلاء المؤقتين.
* **ألغِ التفويض فوراً**: يطبّق الإلغاء أو فقدان الصلاحية مع الطلب التالي.

المسار الأكثر أماناً هو إنشاء رابط صغير أولاً، اختباره، ثم توسيع الصلاحيات فقط عندما يثبت سير العمل أنه يحتاج أكثر.

## خطوات الإعداد

1. **اختر المؤسسة**: حدد مساحة عمل الشركة التي يسمح للوكيل بمساعدتها. هذا يفصل بيانات كل شركة عن الأخرى.
2. **أنشئ رابط وكيل**: اكتب اسماً مفهوماً مثل `مساعد مبيعات ChatGPT` أو `مراجعة مورد Claude` حتى يعرف الجميع سبب وجوده.
3. **حدد الصلاحيات**: ابدأ بالقراءة فقط. شغل الإنشاء أو التحديث فقط عندما يحتاج الوكيل للكتابة داخل كانترا.
4. **انسخ رابط MCP**: الصق الرابط الناتج داخل ChatGPT أو Claude أو Grok أو Codex أو Cursor أو وكيلك المخصص كرابط خادم MCP.
5. **اختبر وأدر الرابط**: اسأل الوكيل عما يستطيع فعله. إذا كان هناك شيء غير صحيح، أوقف الرابط أو دوّره أو ألغِه من الإعدادات.

## أول رابط مقترح

أنشئ الرابط الأول لسير عمل ضيق بدلاً من مساعد واسع الصلاحيات. البداية الجيدة غالباً تكون بهذا الشكل:

| الإعداد | القيمة المقترحة | سبب أهميته |
| --- | --- | --- |
| الاسم | `قارئ عملاء ChatGPT` | يجعل سجلات المراجعة مفهومة لاحقاً. |
| النطاق | العملاء: قراءة | يسمح للوكيل بالإجابة بدون تغيير السجلات. |
| الكتابة | متوقفة | يمنع الإنشاء أو التعديل أو الحذف أثناء الاختبار. |
| المالك | مسؤول المؤسسة | يبقي التدوير والإلغاء عند الشخص المسؤول. |

بعد نجاح الاختبار الأول، أضف الإجراء الناقص فقط. مثال: فعّل `إنشاء` للمهام فقط بعد اتفاق الفريق أن الوكيل يجب أن ينشئ مهام متابعة من المحادثة.

## شكل رابط MCP

الرابط الناتج سر. تعامل مع القيمة كاملة مثل كلمة مرور، والصقها فقط داخل إعدادات موصل موثوق.

```txt
https://your-domain.com/api/mcp/agent/PUBLIC_ID/SECRET
```

يمكن مشاركة التوثيق العام بحرية، لكن لا تلصق قيمة `SECRET` الحقيقية داخل تذكرة، صورة شاشة، بريد، كونسول المتصفح، أو رسالة إلى نموذج ذكاء اصطناعي.

## مثال إعداد الموصل

أغلب الوكلاء السحابيّين يطلبون رابط خادم MCP بعيد. الشاشة تختلف حسب المنتج، لكن القيم عادة تشبه هذا المثال:

```json
{
  "name": "Qentrah clients",
  "transport": "streamable-http",
  "url": "https://your-domain.com/api/mcp/agent/PUBLIC_ID/SECRET"
}
```

إذا طلب المنتج ترويسات إضافية، اتركها فارغة ما لم يكن نشر كانترا عندك خلف بوابة إضافية. سر كانترا موجود بالفعل داخل رابط MCP.

## إعداد MCP على سطح المكتب

بعض الوكلاء يقرأون ملف إعداد محلي بصيغة JSON. في هذه الحالة، ضع السر في متغير بيئة واحد واجعل ملف الإعداد يشير إليه. هذا يجعل تدوير الرابط أسهل لأنك لا تحتاج إلى تعديل ملف التطبيق في كل مرة تصدر فيها رابطاً جديداً.

```json
{
  "mcpServers": {
    "qentrah-clients": {
      "transport": "streamable-http",
      "url": "${QENTRAH_MCP_URL}"
    }
  }
}
```

```bash
export QENTRAH_MCP_URL="https://your-domain.com/api/mcp/agent/PUBLIC_ID/SECRET"
```

بعد حفظ الإعداد، أعد تشغيل الوكيل واطلب منه عرض أدوات كانترا المتاحة. إذا لم تظهر الأدوات، تأكد أن الرابط نُسخ كاملاً، وأنه ما زال فعالاً، وأن المؤسسة تسمح بالنطاقات المختارة.

## مثال زر React

استخدم إجراء عادياً في لوحة التحكم لإرسال المسؤول إلى شاشة إنشاء الرابط الحقيقية. إنشاء الرابط يبقى داخل كانترا حتى تبقى الصلاحيات، وسجل المراجعة، وإظهار السر مرة واحدة في الخادم.

```tsx
import { Plus } from "lucide-react";
import Link from "next/link";

export function CreateQentrahAgentLink() {
  return (
    <Link
      href="/ar/dashboard/organization?tab=agent-links&action=new"
      className="inline-flex h-10 items-center gap-2 rounded-md bg-primary px-3 text-sm font-bold text-primary-foreground"
    >
      <Plus className="h-4 w-4" />
      رابط وكيل جديد
    </Link>
  );
}
```

## مثال تحميل حالة الروابط في React

لوحة التحكم الطويلة يجب أن تحمل حالة الروابط من الخادم، ولا تحفظ الأسرار المنسوخة داخل المتصفح. الواجهة تحتاج بيانات آمنة فقط: الاسم، النطاقات، حالة التفعيل، آخر استخدام، وما إذا كان التدوير مطلوباً.

```tsx
import { useEffect, useState } from "react";

type AgentLinkStatus = {
  id: string;
  name: string;
  scopes: string[];
  active: boolean;
  lastUsedAt: string | null;
};

export function QentrahAgentLinksStatus() {
  const [links, setLinks] = useState<AgentLinkStatus[]>([]);

  useEffect(() => {
    let cancelled = false;

    async function loadLinks() {
      const response = await fetch("/api/qentrah/agent-links", {
        headers: { Accept: "application/json" },
      });
      const payload = (await response.json()) as { links: AgentLinkStatus[] };

      if (!cancelled) {
        setLinks(payload.links);
      }
    }

    loadLinks();
    return () => {
      cancelled = true;
    };
  }, []);

  return (
    <ul>
      {links.map((link) => (
        <li key={link.id}>
          <strong>{link.name}</strong>
          <span>{link.active ? "فعال" : "متوقف"}</span>
          <span>{link.scopes.join(", ")}</span>
        </li>
      ))}
    </ul>
  );
}
```

لا ترجع `SECRET` من هذا المسار. أظهر السر مرة واحدة عند إنشاء الرابط، ثم اعرض الحالة الآمنة وأزرار التدوير فقط.

## قائمة اختبار سريعة

اختبر الرابط قبل إضافة صلاحيات أوسع:

1. اطلب من الوكيل عرض الأدوات التي يستطيع استخدامها.
2. اطلب منه قراءة سجل آمن، مثل ملخص عميل عام.
3. تأكد أنه لا يستطيع الكتابة إذا كان الرابط للقراءة فقط.
4. راجع نشاط المؤسسة أو سجلات استخدام MCP.
5. دوّر الرابط إذا ظهر أثناء الإعداد.

## متى تنشئ رابطاً آخر

أنشئ رابطاً منفصلاً عندما يتغير الغرض أو الوكيل أو مستوى الصلاحيات. مساعد المبيعات الذي يقرأ العملاء، وأتمتة العمليات التي تنشئ المهام، ومساعد مراجعة الموردين لا يجب أن يتشاركوا سراً واسعاً واحداً.

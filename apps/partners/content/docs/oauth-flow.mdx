---
title: Legacy manual OAuth
description: Manual OAuth is no longer the standard integration path. Use the Qentrah SDK unless your team has custom infrastructure requirements.
---

The recommended path is the [SDK installation guide](/docs/sdk-installation). It handles the authorization redirect, PKCE, state validation, token exchange, refresh helpers, and friendly errors for you.

Use manual OAuth only if your team has a custom OAuth framework that cannot use `@qentrah/auth-sdk`.

## Recommended replacement

```bash
npm install @qentrah/auth-sdk
```

```html
<button id="qentrah-authorize">Authorize with Qentrah</button>
<script src="https://cdn.jsdelivr.net/npm/@qentrah/auth-sdk@0.1.5/dist/qentrah-auth.js"></script>
<script>
  window.QentrahAuth.mountAuthorizeButton({
    buttonId: "qentrah-authorize",
    startUrl: "/api/qentrah/oauth/start"
  });
</script>
```

Then add backend routes with `createQentrahPartnerAuthHandlers`.

```ts
import { createQentrahPartnerAuthHandlers } from "@qentrah/auth-sdk/partner/next";

const handlers = createQentrahPartnerAuthHandlers({
  workspaceBaseUrl: process.env.QENTRAH_WORKSPACE_API_URL!,
  clientId: process.env.QENTRAH_CLIENT_ID!,
  clientSecret: process.env.QENTRAH_CLIENT_SECRET,
  redirectUri: `${process.env.PARTNER_APP_URL}/api/qentrah/oauth/callback`,
  scopes: ["organization:read", "client:read"],
  sessionStore,
  tokenStore,
});

export const GET = handlers.start;
```

The callback route should export `handlers.callback`.

## What changed

- Partners should not build authorization URLs by hand.
- Partners should not implement PKCE/state/token exchange themselves unless they have a strong reason.
- Browser code should only open your backend start route.
- Tokens, client secrets, webhook secrets, and authorization codes must stay server-side.

## Expiry and reconnection

Organization authorization expires after the app's configured authorization lifetime. Workspace rejects expired connections with `connection_expired`. Send the workspace admin through Authorize with Qentrah again to reconnect.

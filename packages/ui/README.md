# @anan/ui

General Anan React UI primitives. AI/protocol rendering remains in
`@anan/ag-ui`. App wrappers own Next routing, labels, and route state.

Exports include `@anan/ui/admin`, `@anan/ui/forms`, `@anan/ui/workspace`,
`@anan/ui/docs`, `@anan/ui/auth`, `@anan/ui/public`, `@anan/ui/chat`, and
small shadcn-style primitive subpaths.

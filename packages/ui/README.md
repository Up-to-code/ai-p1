# @qentrah/ui

General Qentrah React UI primitives. AI/protocol rendering remains in
`@qentrah/ag-ui`. App wrappers own Next routing, labels, and route state.

Exports include `@qentrah/ui/forms`, `@qentrah/ui/docs`, `@qentrah/ui/auth`,
`@qentrah/ui/public`, `@qentrah/ui/chat`, and
small shadcn-style primitive subpaths.
